# Lusco Portfolio — Editorial + Neo-Brutalism

Landing page autoral em HTML/CSS/JavaScript com GSAP + ScrollTrigger.

## Estrutura
- `index.html`
- `styles.css`
- `script.js`
- `assets/lusco-logo.svg`
- `assets/joao-studio.png` — retrato editorial tratado, com fundo transparente
- `assets/tentacle-a.svg`, `tentacle-b.svg`, `tentacle-c.svg` — tentáculos ilustrados em SVG

## Executar
Abra `index.html` em um navegador ou sirva a pasta com um servidor local.

Exemplo:
```bash
python -m http.server 8080
```

## Observações
- GSAP e ScrollTrigger são carregados por CDN.
- Os previews dos cases usam WordPress mShots e precisam de internet.
- O layout foi projetado para evitar grids simétricos de cards: os projetos aparecem em uma composição quebrada e editorial.
